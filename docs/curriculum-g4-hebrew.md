# שפה ולשון – כיתה ד' (ממלכתי)

**סטטוס:** החבילה `g4.hebrew` בנויה (`src/curricula/g4/hebrew`): 12 נושאים ב־3 יחידות, עם בנק שאלות, לפי הטבלה שלמטה.

מקורות:
- תוכנית הלימודים "חינוך לשוני: עברית – שפה, ספרות ותרבות" (תשס"ג): https://meyda.education.gov.il/files/Curriculum/hebrew-1-6.pdf
- הישגים נדרשים – ציוני דרך **לסוף כיתה ד'**: https://meyda.education.gov.il/files/Mazkirut_Pedagogit/HebrewPrimary/program/hesegim.pdf
- **מפרט ההערכה בשפת אם עברית לכיתה ד' – תשפ"ו** (ראמ"ה): מבחן חיצוני בהבנת הנקרא, והערכה פנימית בהבעה בכתב ובידע לשוני.
  https://meyda.education.gov.il/files/Rama/Mifrat_Heb_LangH_4_2026.pdf

כיתות ג'–ד' הן מחזור אחד בתוכנית, וציוני הדרך מוגדרים לסוף כיתה ד'.

## ידע לשוני לפי מפרט כיתה ד' ← הצעה לנושאי האפליקציה

| נושא במפרט / בציוני הדרך | נושא מוצע (id) |
|---|---|
| אוצר מילים: משמעות בהקשר, מילים נדירות, ביטויים ומטפורות; נרדפות וניגודיות | `word-meaning` |
| שורש: זיהוי שורשים, משפחות מילים; הבנת המושג "שורש" ותפקידו במשמעות | `root` |
| נטיית השם: מין ומספר, סיומות ויוצאי דופן; שמות המספר בזכר ובנקבה | `gender-number` |
| נטיית הפועל: זיהוי זמנים וגופים ושימוש תקין; שם הפועל ושם הפעולה | `verbs` |
| כינויי קניין: שייכות חבורה (ילדיי, חבריו) לעומת פרודה (הילדים שלי) | `possessives` |
| צירופי סמיכות: זיהוי, יצירה בזכר ובנקבה, ביידוע ובריבוי, ופירוק | `smichut` |
| חלקי דיבור: שם עצם, פועל, שם תואר, תואר הפועל, מילות יחס, מילות קישור | `parts-of-speech` |
| מיליות: מילות קישור (אך, אבל, לכן, משום ש־), מילות יחס, ה הידיעה ו־ו החיבור | `connectives` |
| התאם דקדוקי בגוף, במין, במספר ובזמן | `agreement` |
| סימני פיסוק: נקודה, סימן שאלה, נקודתיים, מרכאות, סימן קריאה, פסיק | `punctuation` |
| כתיב: כתיב תקני; סימני הניקוד וקריאה לפיהם; מילים הומוגרפיות (שוות כתיב, שונות הגייה) | `spelling-niqqud` |
| הבנת הנקרא: משמעות גלויה, משמעות משתמעת, פרשנות ויישום, הערכת תוכן, מבנה ולשון | `reading` |

## הערות לבנייה
- חלק גדול מבנק השאלות של `g5.hebrew` מתאים לרמות 1–2 כאן (שורש, סמיכות, מילות קישור, פיסוק). כדאי לכתוב בנק נפרד ופשוט יותר, ולא לשתף נושאים בין כיתות, כדי שההתקדמות של כל ילד תישמר לפי הכיתה שלו.
- ניקוד ומילים הומוגרפיות דורשים טקסט מנוקד; `normalizeText` כבר מתעלם מניקוד בהקלדה, ולכן אפשר לשאול "איך קוראים את המילה?" בבחירה.
