# מתמטיקה – כיתה ד' (ממלכתי)

**סטטוס:** החבילה `g4.math` בנויה (`src/curricula/g4/math`): 17 נושאים ב־5 יחידות, עם מחוללי שאלות כמו בכיתה ה׳.

מקור: משרד החינוך, "תכנית לימודים במתמטיקה לכיתות א–ו בכל המגזרים" (2006), פרק כיתה ד' (עמ' 75 ואילך).
https://meyda.education.gov.il/files/Tochniyot_Limudim/Math/Yesodi/kita4.pdf

**חשוב לבדוק לפני שבונים:** לפי חוזר המפמ"ר לתשפ"ז, תוכנית 2006 עדיין בתוקף בכיתות ד'–ו', והתוכנית החדשה הוטמעה רק בכיתות א'–ג'. ההטמעה מתקדמת בשכבה אחת בכל שנה, כך שבתשפ"ח כיתה ד' עשויה לעבור לתוכנית החדשה. לבדוק את חוזר המפמ"ר של השנה לפני שבונים את החבילה.
