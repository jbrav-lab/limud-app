# Security policy

This app is a learning app for children. It holds learning progress for a small number of families and no payment data.

## Reporting a vulnerability
Please report privately through **GitHub's private vulnerability reporting**: the **Security** tab of this repository → **Report a vulnerability**.
Do not open a public issue, and do not include real children's data in a report.

We aim to acknowledge reports within a few days. Fixes are deployed through the normal pipeline, which runs a dependency audit, the full test suite and security checks before every release.

## Scope
- The web app at https://jbrav-lab.github.io/limud-app/ and the code in this repository.
- Out of scope: denial-of-service tests, social engineering, and anything that touches other people's devices or data.

How the app protects data: [docs/security-privacy.md](docs/security-privacy.md).
